# H_kaijo（保留解除依頼書_作成支援）の配布

株式会社エクシード関西の社内で使う「保留解除依頼書_作成支援」のインストーラーを置く場所です。
プログラムの本体はここにはありません。

## 入れ方

[最新のインストーラー（H_kaijo_setup.exe）](https://github.com/Tom-Yam-Kun/H_kaijo-releases/releases/latest/download/H_kaijo_setup.exe)
を落として、ダブルクリックします。管理者の権限は要りません。

一度入れると、アプリが起動のたびにここを確かめ、新しい版があれば更新を聞きます。

## 置いてあるもの

各 Release に次の2つを置きます。

- `H_kaijo_setup.exe` … インストーラー
- `latest.json` … 最新の版と、インストーラーの SHA-256（アプリの自動更新が見る）
